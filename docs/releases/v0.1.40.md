# PDFCompare Local v0.1.40

Обновлён дизайн AI-отчёта.

В матрице листов вместо одинакового служебного текста в каждой строке теперь перечислены изменённые
объекты: красным — правки, оранжевым — наблюдения, которые AI не подтвердил и которые нужно проверить.
Список пересчитывается с учётом ручной оценки: если пометить зону шумом, она исчезает из сводки.
Над матрицей добавлен фильтр листов «Все / С правками / Проверить / Без правок».

На странице листа зоны подписаны названиями объектов. Для наблюдений со структурированным ответом
модели показаны значения OLD и NEW и последствие правки. Если номера ревизий неизвестны, подписи
«OLD · OLD» больше не выводятся.

Формат данных AI-отчёта не изменился. Уже выданные отчёты остаются в прежнем виде.
