# PDFCompare Local v0.1.4

This release brings the desktop GUI to full parity with the MCP server's comparison controls and metrics, and documents the full MCP tool surface.

## Added

- **GUI comparison options:** experimental bbox merge (toggle + gap mm + max-area ratio) and a debug-images toggle, now passed through to `compare_pdfs` like the MCP/CLI already do.
- **Visual exclusion picker:** a ✏ Pick… button on the Compare tab opens a window to draw exclude regions on a rendered PDF page. Multiple rectangles are supported and appended to the exclude field in `x,y,w,h` percent form.
- **Re-render metrics:** the Re-render tab now shows `FG %` (foreground-relative) and `mm²` (physical changed area) columns per row, in addition to the existing `Diff %`.
- **Re-render overrides:** stroke tolerance, strictness, exclusion regions, and bbox merge can now be overridden on the Re-render tab. Empty fields inherit the values stored in the original report (the same `None`-inherit convention the MCP rerender tool uses).
- **Per-page (mixed) rerendering:** a new per-page mode lets you apply different settings to selected sheets (e.g. recompute sheet 4 strictly, sheet 7 loosely) via `regenerate_report_pages_mixed`.
- **CLI flags:** `--bbox-merge-gap-mm` and `--bbox-merge-max-area-ratio` for parity with GUI and MCP.

## Changed

- Moved packaging, requirements, launchers, and agent setup prompt files into dedicated folders to keep the repository root smaller.
- The `start_pdf_comparison` signature documented in `LOCAL_AGENT_MCP.md` now lists the full parameter set (`diff_strictness`, `exclude_regions`, `bbox_merge_max_area_ratio`, `keep_debug_images`).

## Fixed

- PyInstaller spec resolves its root from `SPECPATH` after the spec moved into `packaging/`, so EXE builds work regardless of the invocation working directory.
