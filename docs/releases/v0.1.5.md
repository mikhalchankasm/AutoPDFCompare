# PDFCompare Local v0.1.5

Hotfix for an out-of-memory crash that affected large engineering drawings.

## Fixed

- Resolved `cv2.error: (-4:Insufficient memory) Failed to allocate ~1.16 GB` in `compute_diff_detailed` on large A0/A1 sheets rendered at high DPI. The two full-frame `distanceTransform` float32 buffers are now computed and released one at a time instead of being held in memory simultaneously, roughly halving peak memory usage in the diff engine.
- Added a render-area guard: pages rendered above `MAX_RENDER_MEGAPIXELS` (40 MP, roughly an A1 sheet at 250 DPI) are area-downscaled before entering the diff pipeline, keeping peak memory bounded while preserving stroke geometry.

## Verification

- Test suite: `84 passed, 9 subtests passed`.
