# PDFCompare Local v0.1.1

Report usability update.

## Added
- Previous/next controls on slider comparison pages.
- Hover/click sheet picker on slider pages with status, diff percentage, change-zone count, and search.
- `Save DIFF as` action on detail and slider pages to download the current sheet overlay image.

## Changed
- Current sheet highlighting in report navigation is stronger and easier to spot.
