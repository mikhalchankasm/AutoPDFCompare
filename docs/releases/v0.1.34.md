# PDFCompare Local v0.1.34

Явное сравнение одной пары страниц в движке и MCP.

- `preview_pdf_comparison` и `start_pdf_comparison` принимают `force_single_pair=true`. Каждый входной PDF должен содержать ровно одну страницу.
- Выбранные страницы сравниваются между собой, без автоматического поиска соответствий. Это позволяет проверять выбранную пару даже при больших различиях между ревизиями.
- Физические зоны исключения, эффективный DPI, лимит мегапикселей и отмена сохраняют прежнее поведение. По умолчанию сопоставление остаётся автоматическим.

Проверки: Ruff, mypy, регрессионные тесты и отдельные проверки явной пары и отклонения многостраничных входов.
