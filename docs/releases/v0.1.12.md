# PDFCompare Local v0.1.12

Slider report: pinned-by-default sheet navigation. Exclusion picker rework.

## Added

- In the slider comparison view, the sheet navigation sidebar is now **pinned by default** — it sits on the left and pushes the comparison content to the right, so you can click any sheet directly instead of hovering the left edge to reveal it. A 📌 button in the panel header toggles back to the previous floating (hover-to-open) behavior. The pin/unpin state is saved in localStorage and applies to all slider pages.
- **Exclusion picker rework** (GUI → "Exclude regions" → pick button):
  - millimetre grid overlay with selectable step (off / 5 / 10 / 25 / 50 mm);
  - paper format auto-detection (A4/A3/A2/A1/A0 or custom size readout) with a manual override for scans whose nominal paper size differs from the PDF page size;
  - live size label in mm while drawing or resizing a box; every box shows its "W×H mm" size;
  - boxes are editable: click to select, drag to move, 8 resize handles, Del/Backspace removes the selected box, Esc deselects;
  - page switcher for multi-page documents;
  - regions already present in the field (percent, mm or px units) open as editable boxes; OK replaces the field with the edited set, so zones can be removed too;
  - **corner anchors**: each zone can be anchored to ↖/↗/↙/↘. A bottom-right anchor keeps a stamp zone in place on sheets of different formats; the anchored corner is marked on the box and offsets in the readout are measured from it. Anchored sets are stored in the field as JSON (`unit: percent`, `anchor: …`); top-left-only sets keep the old `x,y,w,h` text.
- **Re-render tab**: the uniform "Exclude regions" field got the same picker button — it opens the loaded run's old PDF (with the selected row's page when exactly one row is selected) and pre-loads the field's current zones for editing.

## Fixed

- Pinned sidebar collapsed the slider view: the comparison stage squeezed into the 48px header row and auto-fit zoomed to ~1%. The layout grid is restructured — the page grid splits only sidebar/content columns, while the main column owns the header/stage/controls rows.
- Pin state was not persisted (undefined variable in the pin handler).
- Toggling the pin re-fits the image to the new viewport width.
- Embedded slider (iframe on the sheet view page) no longer reserves the pinned sidebar column and hides the drawer entirely.
