# PDFCompare Local v0.1.36

Исправлено ложное завершение MCP-сравнения при параллельной обработке больших комплектов.

- Python `spawn` повторно импортировал модуль worker в каждом дочернем процессе. Эти процессы перезаписывали `worker.json` своим PID. После завершения дочернего процесса MCP мог ошибочно объявить основной worker погибшим и удалить ещё используемый временный отчёт.
- Идентификатор публикует только основной процесс, до тяжёлых импортов. Дочерние процессы сохраняют его без изменений. Проверка PID по времени создания и безопасная отмена сохранены.
- Очистка повторно читает статус после обнаружения завершившегося процесса, чтобы не заменять уже записанное `completed` ошибкой из устаревшего снимка.

Включены улучшения v0.1.35: уникальное обозначение DWG в штампе сохраняет соответствие страниц при изменении формата бумаги.

Проверки: Ruff, mypy, регрессии spawn-импорта и гонки очистки, полный набор тестов; полный серверный прогон комплекта больших чертежей с несколькими worker.
