# PDFCompare Local v0.1.6

Adds a zoom-to-rectangle gesture to the slider comparison view.

## Added

- In the HTML report's slider mode, press and drag the **middle mouse button** (wheel button) to draw a rectangle; on release the view zooms to fit that rectangle. This complements the existing left-drag (move split divider) and right-drag (pan) gestures. The browser's default middle-click autoscroll is suppressed while dragging. Use the Fit button or Ctrl+wheel to zoom back out.
