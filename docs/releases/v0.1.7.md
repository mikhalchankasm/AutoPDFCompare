# PDFCompare Local v0.1.7

Adds an automatic update-check so the desktop app can tell you when a newer release is available.

## Added

- On launch, the app checks the GitHub releases API (at most once every 24 hours) and, if a newer version exists, shows a dialog: "Version {x} is available. Open the download page?" with Yes / No. Choosing Yes opens the release page in your default browser.
- A clickable update badge (★ {version}) appears in the header next to the language switcher while an update is pending.
- The gear icon in the top-right corner now triggers a manual "check for updates now" (bypasses the 24h gate).
- "Skip this version" — after declining an update, you can opt to stop being reminded about that specific version. The badge remains available via the manual check.
- Automatic checks fail silently on network errors; manual checks show a brief warning if the check fails.
- The check interval, enabled flag, last-checked timestamp, and skipped version are persisted in `~/.pdfcompare_local/state.json`.

## Notes

- This is a notify-only feature: it opens the download page in your browser. The app does not download or replace the EXE itself (the onefile EXE cannot overwrite itself while running).
- The only network request goes to the public GitHub API (`api.github.com`). No telemetry is sent.
