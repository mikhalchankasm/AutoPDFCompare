# PDFCompare Local v0.1.38

В AI-отчёте можно вручную изменить классификацию наблюдения на «правка», «шум» или «проверить»,
а затем вернуть исходный вывод AI. Сводка пересчитывается с учётом ручных решений. На главной странице
появился общий переключатель «По умолчанию показывать только правки на всех листах».

Решения сохраняются локально в браузере. Переходы кнопками отчёта переносят их между локальными HTML;
исходные JSON/ZIP, модель и серверный кэш не редактируются. Для другого браузера или новой копии
каталога отчёта локальное сохранение не гарантируется.

Просмотрщик поддерживает приблизительные контуры объектов вместо обязательных прямоугольных зон
и отдельное оранжевое обозначение неопределённости. Скрытые фильтром зоны скрываются и на чертеже.

В отдельной поставке Telegram-сервиса фрагменты служат для чтения листа, а находки формируются
по объектам. Красная метка требует читаемых OLD → NEW фактов изменения проекта. Печать, сглаживание,
шрифты и перенос неизменённого блока считаются оформлением; неподтверждённые выводы требуют проверки.
Кэш прежнего формата сохраняется, новый анализ требует новых обращений к провайдеру.

Приватный Telegram-сервис по-прежнему не входит в публичную сборку.
