# PDFCompare Local v0.1.30

Небольшой security-релиз поверх v0.1.29.

- `cryptography` обновлена с 49.0.0 до 50.0.0 — исправление `PYSEC-2026-3552`.
- Зафиксированный сборочный `pip` обновлён с 26.1.2 до 26.2.1 — исправление `PYSEC-2026-3721`.
- Полный CI-lock и облегчённый runtime-lock перегенерированы с SHA-256 хешами под Windows / CPython 3.12.

Функциональность визуального AI-сравнения, персональные ключи DeepSeek/Qwen и новый интерактивный отчёт находятся в v0.1.29 и без изменений входят в этот релиз.
