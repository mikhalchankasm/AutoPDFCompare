# PDFCompare Local v0.1.3

This release focuses on safer agent-driven PDF comparison and more meaningful change metrics for engineering drawings.

## Added

- Per-page MCP rerendering for recalculating selected report rows with different DPI, strictness, stroke tolerance, bbox merge, and exclusion settings.
- Safe rerender staging: selected pages and HTML are rebuilt in temporary folders first, then swapped into the existing report only after successful generation.
- Visible custom precision markers in the HTML report for rows recalculated with per-page settings.
- Exclusion regions for ignoring title blocks, stamps, author tables, or other areas during diff calculation.
- Diff strictness presets: `strict`, `normal`, and `loose`.
- New report metrics:
  - `Diff %`: changed pixels divided by the whole page area.
  - `FG %`: changed pixels divided by drawing foreground/content pixels.
  - `mm²`: physical changed area, stable across different render DPI.

## Changed

- Bbox merge remains disabled by default and is documented as experimental.
- Optional bbox merge now groups from the diff mask and rejects sparse, page-sized boxes to avoid large empty rectangles.
- Change severity can use content-relative `FG %` when available, instead of relying only on whole-page `Diff %`.

## Fixed

- Prevented page-sized sparse contours from appearing as one huge bbox.
- Prevented in-place rerender failures from deleting the only copy of page assets before a successful rebuild.

- Test suite: `72 passed, 9 subtests passed`.
