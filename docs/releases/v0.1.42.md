# PDFCompare Local v0.1.42

Обмен ручными решениями AI-отчёта между коллегами.

До сих пор решения по зонам («Правка / Проверить / Шум») и поправленные контуры хранились только в браузере
того, кто их принял, и в ссылке между листами. Коллега, получивший ZIP отчёта, их не видел.

На странице обзора AI-отчёта появились кнопки «Сохранить решения» и «Загрузить решения». Первая скачивает
JSON-файл с решениями и контурами, вторая загружает такой файл в открытый отчёт. Решения привязаны к зонам
отчёта, а не к папке, в которую он распакован, поэтому файл подходит к любому экземпляру того же отчёта.
Записи, не относящиеся к зонам этого отчёта, пропускаются; страница сообщает, сколько загружено и сколько
пропущено. Файл другого формата не принимается.

Формат данных AI-отчёта не изменился. Уже выданные отчёты остаются в прежнем виде.
