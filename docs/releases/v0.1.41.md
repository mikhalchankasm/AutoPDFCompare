# PDFCompare Local v0.1.41

Ручная доработка AI-отчёта на странице листа.

Решение по зоне принимается тремя кнопками «Правка / Проверить / Шум» прямо под заголовком зоны
(клавиши 1–3). Рядом видно, совпадает ли решение с выводом AI; вернуть вывод AI можно одним щелчком.
Зоны с ручным решением помечены в списке; зона, которую текущий фильтр скрыл бы после смены класса,
остаётся в списке, пока она выбрана.

Контур зоны, нанесённый AI, можно поправить: кнопка «Править контур» (клавиша E) позволяет сдвинуть
контур, перетащить вершины, добавить вершину двойным щелчком по ребру и удалить Alt+щелчком; Ctrl+Z
отменяет шаг, Esc завершает правку, «Вернуть контур AI» восстанавливает исходный. Детальный фрагмент
OLD / NEW строится по новому контуру. Поправленные контуры хранятся в браузере вместе с ручными
решениями и передаются ссылкой между листами; исходный вывод AI не меняется.

На каждой странице листа появилась кнопка «Листы» — перечень всех листов отчёта со счётчиками правок
и «проверить», главными объектами и превью OLD / NEW.

Исправлено: в AI-отчёте, построенном приложением, кнопки перехода между листами вели и на листы,
для которых нет ответа AI.

Формат данных AI-отчёта не изменился. Уже выданные отчёты остаются в прежнем виде.
