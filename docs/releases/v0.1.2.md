# PDFCompare Local v0.1.2

## Highlights

- Added local stdio MCP support for agent-driven PDF comparisons.
- Added one-click Cursor/VS Code MCP install buttons and a root `SETUP_PROMPT.md` for generic local agents.
- Added a bootstrap MCP wrapper that refreshes dependencies, starts the server, and supports opt-in repository updates.
- Added named report folders through CLI `--run-name`, GUI report-name field, and core `run_name` support.
- Updated portable ZIP packaging to include runtime modules, MCP scripts, prompt docs, and setup files.

## Downloads

- `PDFCompareLocal.exe` is the easiest Windows option and does not require Python.
- `PDFCompareLocal-portable.zip` is for Python-based portable use and includes MCP setup files.
