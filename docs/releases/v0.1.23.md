# PDFCompare Local v0.1.23

Папка отчёта одним полем, подсветка зон изменений и кнопка «Домой» в отчёте.

## Одно поле «Папка отчёта» вместо «Папка вывода» + «Имя отчёта»

Раньше путь запуска собирался из двух половин, а пустое имя молча превращалось в папку с датой в названии. Теперь в поле лежит путь папки, которую создаст запуск: его можно вставить из буфера и дописать руками.

- Кнопка **«Сгенерировать имя»** собирает имя из имён обоих PDF: общая часть пишется один раз, дальше обе ревизии (`Проект_рев5.pdf` + `Проект_рев6.pdf` → `Проект_РЕВ5_vs_РЕВ6`), занятое имя получает суффикс.
- Если в поле уже лежит **существующая** папка, она считается контейнером — имя внутри неё подбирается само. «Выбрал папку, нажал Сравнить» больше не пишет отчёт поверх чужого содержимого.
- Метка ревизии сохраняет префикс: `plan_r1` → `R1`, а не `1` (иначе `plan_1_vs_2` читается как диапазон страниц). То же имя предлагает MCP-инструмент `prepare_pdf_comparison` — логика вынесена в общий `pdfcompare_core/run_names.py`, чтобы GUI и MCP не расходились.

## Папка создаётся до запуска, и её отказ виден сразу

Ошибка создания (недоступный путь, файл на месте папки, недопустимое имя) останавливает запуск и показывает предупреждение — а не всплывает через несколько минут из воркера.

## Слайдер: три доработки по следам реальной работы

- **Кнопка «Зоны» — трёхсекундная подсветка мест, где сосредоточены изменения.** Иногда правки слабочитаемы: видно, что лист «Изменён», но не видно куда смотреть. Кнопка (клавиша `z`) вписывает лист целиком, группирует рамки bbox в зоны сосредоточения и на ~3 секунды обводит каждую **габаритной рамкой** с пульсирующим свечением, а внизу показывает счётчик «Зон с изменениями: N». Рамка строится по фактическим границам зоны — стопроцентное попадание, в отличие от круга, который разрастался до большей стороны и вылезал за лист, когда изменение шло вдоль края. Всё считается в браузере из уже имеющихся данных bbox — движок диффа не затронут.
- **Кнопка «Домой» на любой странице — в самое начало, к матрице изменений.** В слайдере пути назад к матрице не было вовсе (только «К листу»). Теперь в шапке есть кнопка с домиком и неоновым контуром, ведущая на `index.html`: в слайдере — компактная круглая иконка слева, в детальном виде — с подписью. Контур светится постоянно (не пульсирует, чтобы не отвлекать при чтении чертежа) и ярче по наведению.
- **Управление рамками (bbox) — строкой в шапке, а не в выпадающем списке.** Цвет и прозрачность правят, *глядя на лист*; каждая корректировка стоила «открыть меню → выбрать → закрыть → посмотреть → открыть снова». Теперь ON/OFF, три цвета и ползунок лежат открытыми в верхней панели. Заодно появилась кнопка «В начало» листа (клавиша `Home` работала и раньше, но её никто не видел).

## Fixed

- **Подписи кнопок листов ломались на две строки и выпирали из шапки слайдера.** Кнопка — flex-элемент и может сжаться уже своего содержимого: «Лист 9» переносился как «Лист» / «9», а шапка высотой ровно 48 px не давала кнопке места. Подписи больше не переносятся, а шапка при нехватке ширины сначала прячет хвост с метриками, потом подписи, и только затем переносит управление на вторую строку. Дублирующий счётчик «Лист 5 / 12» из навигации убран — он есть в заголовке.
