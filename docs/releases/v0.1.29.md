# PDFCompare Local v0.1.29

## Визуальная AI-проверка через MCP

- Добавлен двухшаговый сценарий: `preview_pdf_vision_analysis` сначала без сети показывает точный перечень листов и предупреждение о внешней передаче, а `analyze_pdf_comparison_with_ai` запускается только после явного подтверждения.
- Поддерживаются личные ключи DeepSeek и Qwen. Ключ читается исключительно из окружения MCP-процесса, не принимается аргументом инструмента и не записывается в кэш, отчёт или ZIP.
- При отсутствии настройки агент получает безопасную инструкцию с названием требуемой переменной окружения и напоминанием не передавать секрет в чат.
- Qwen подключается через официальный Alibaba Model Studio compatible-mode endpoint. Перед запросом MCP проверяет HTTPS, домен Alibaba и путь endpoint, чтобы ключ нельзя было случайно отправить на произвольный адрес.
- Кэш разделён по провайдеру, модели, языку и версии промпта. Повторное формирование отчёта использует сохранённый анализ без нового API-запроса.

## Какие данные могут уйти во внешний API

Только после подтверждения отправляются JPEG-монтажи сопоставленных изменённых пар OLD + NEW с машинным DIFF и нумерованными зонами. Исходные PDF, добавленные, удалённые, односторонние, неизменённые, несопоставленные и явно исключённые листы не отправляются.

## Новый отчёт

- Общая матрица листов и отдельная страница каждого листа.
- Полноразмерный lossless PNG-слайдер OLD/NEW, логические зоны и отдельные PNG-кропы.
- Масштабирование, панорама, нижняя навигация, копирование описания в Markdown.
- Шумовые зоны показаны по умолчанию и выделены синим, чтобы не сливаться с красными подтверждёнными изменениями.
- Локальные HTML, Markdown, JSON и ZIP создаются в каталоге завершённого сравнения.

## Совместимость и стоимость

Прежний `analyze_pdf_comparison_with_deepseek` сохранён как DeepSeek-only alias. Для DeepSeek итог содержит расчёт стоимости по фактическим токенам; для Qwen возвращаются токены без встроенной цены, поскольку тариф зависит от региона и условий аккаунта Alibaba Model Studio.
