# PDFCompare Local v0.1.31

Сервисный релиз по результатам контрольного ревью кода.

- Автообновление скачивает установщик в уникальный временный файл и дважды проверяет его SHA-256: после загрузки и непосредственно перед запуском. Непроверенный файл никогда не запускается.
- Нефатальные ошибки интерфейса и служебных операций теперь сохраняются в ротируемый журнал `~/.pdfcompare_local/pdfcompare.log`, который корректно закрывается вместе с приложением.
- Аудит известных уязвимостей зависимостей стал блокирующим релизным гейтом. Обычный push в `master` выполняет проверки, но не собирает лишние дистрибутивы.
- Свободный диапазон OpenCV ограничен текущей основной версией `>=5.0,<6`; добавлены исключения для локальных кэшей Ruff и mypy.

Проверка: Ruff и mypy без замечаний; публичный набор — 265 тестов прошли, 1 платформенный тест пропущен, покрытие core — 86,53%.
