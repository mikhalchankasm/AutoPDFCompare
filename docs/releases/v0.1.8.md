# PDFCompare Local v0.1.8

GUI polish: taller window, checkboxes instead of on/off chips, removed workers control, always-active buttons, and a live "report ready" banner.

## Changed

- Increased default window height (740→820 px) and minimum height (640→700 px) so the bottom action buttons are visible on launch.
- Replaced the bbox-merge and debug-images on/off chips with checkboxes — the pressed/unpressed state is now visually obvious.
- Reformulated the stroke-tolerance hint: "Higher — ignores thicker lines and minor noise. Lower — catches finer differences."
- Removed the Workers (Auto/1/4) control entirely; the app always uses automatic parallel processing. Users no longer need to think about process counts.
- Open Report and Open Folder buttons next to Run are now always enabled. If no report/folder exists, they show an informational message instead of being greyed out.
- Removed the duplicate Open report / Open folder hyperlinks from the status bar (they duplicated the action buttons).

## Added

- A bold, clickable "✓ Report ready to open" banner appears in the status bar as soon as a live report becomes available mid-comparison. It disappears when the run completes, is cancelled, errors out, or a new run starts.
- Hint label under the report-name field explaining it is optional (empty value = auto-generated timestamped folder name).

## Verification

- Test suite: `101 passed, 9 subtests passed`.
