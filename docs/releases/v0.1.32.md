# PDFCompare Local v0.1.32

Релиз надёжности, производительности и исправлений по итогам аудита.

- Перегенерация отчёта сохраняет исходные файлы и резервные копии при сбоях; повторный откат больше не повреждает восстановленные страницы.
- MCP остаётся доступен для статуса и отмены во время тяжёлых операций. На Linux отмена завершает всю проверенную группу процессов, включая дочерние процессы, игнорирующие SIGTERM.
- Кэш AI-анализа инвалидируется при изменении изображений или метаданных листов.
- Сопоставление листов ускорено: синтетический assignment 200×200 сократился с 2,37 до 0,45 с. Это замер отдельного этапа, а не полного сравнения PDF.
- Установка проверяет соответствие зависимостей hash-lock; portable-пакет содержит все необходимые модули MCP и проверки окружения.
- Gemini 3.7 Flash через OpenRouter используется как экономичный vision-режим MCP по умолчанию; Qwen 3.8 Max доступен для детального анализа. Отправка изображений требует явного подтверждения.

Релиз проходит обязательные Ruff, mypy, тесты с покрытием core не ниже 82% и аудит известных уязвимостей зависимостей. Дистрибутивы: отдельный EXE, portable ZIP и установщик; SHA-256 опубликованы в `SHA256SUMS.txt`.
