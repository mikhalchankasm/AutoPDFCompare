# PDFCompare Local v0.1.15

Correctness and safety release: everything from the external repository review, plus a reworked exclusion-zone picker.

**Important:** the review fixes below landed *after* the `v0.1.14` tag, so the binaries published as `v0.1.14` do not contain them. This is the first release that does — if you installed `v0.1.14`, update.

## Fixed (engine)

- **Render megapixel cap is applied before rasterization** — the effective DPI is derived from the page geometry before `get_pixmap`, so a large sheet at high DPI no longer allocates a multi-gigabyte raster that was merely downscaled afterwards.
- **Physical metrics honor the effective DPI** — when the cap lowers the DPI, mm² areas, mm-based exclusion zones and the bbox merge gap are computed from the DPI the raster actually has. `summary.json` records both `high_dpi` (requested) and `effective_dpi`.
- **Re-rendering is fully transactional** — pages, `summary.json`, CSV/MD, the report bundle and `start.html` are updated as one unit. Any failure (including in the very last step, writing `start.html`) restores the run to its previous, self-consistent state.
- **A failed comparison no longer blocks its run name** — the partial folder is quarantined as `<name>.failed-…` and the same name can be reused immediately.
- **Cancelling stops queued pages** — pending pool futures are cancelled instead of grinding to the end.
- **Uniform DPI validation (72–1200)** across GUI, CLI, MCP and per-page overrides; the per-page dialog no longer crashes on unparseable stroke/gap values.
- **CLI** — passing only one of `--old` / `--new` is an explicit error instead of silently falling back to `--input-dir`.
- **Tkinter is no longer touched from worker threads.**

## Added

- **Auto-update integrity check** — every release ships `SHA256SUMS.txt`; the updater verifies the installer's SHA-256 before running it, deletes the file on mismatch, and refuses a silent install for releases without a manifest. (This protects against corruption and mismatched downloads; it is not a substitute for code signing, which this project does not use.)
- **Schematic sheet mode in the exclusion picker** — picking a format (A4–A0) replaces the real page with a blank sheet of that format in true proportions, with a drawing frame and a dashed 185×55 mm title-block guide, so stamp zones can be traced on a clean sheet. "Auto" restores the real page.
- **Backdrop PDF in the picker** — load any other PDF as the visual reference to trace over; the choice is remembered between runs. Zones stay in percent of the page and apply to the compared documents as usual.
- **History stores every parameter** — bbox-merge options and the debug-images flag are now recorded, and snapshots capture the full input set (previously restoring a snapshot wiped the exclusion-zone field).
- **PR checks + coverage gate** — lint and tests run on pull requests in a read-only job; `pdfcompare_core` coverage must stay ≥ 82%.
- **MIT license** (PyMuPDF remains AGPL-3.0/commercial; its terms apply to distributed builds regardless).
