# PDFCompare Local v0.1.11

Update-check frequency and button visibility.

- Update check interval reduced from 24 hours to 1 hour — the app now checks for new releases on launch if at least one hour has passed since the last check.
- Replaced the gear (⚙) icon with an explicit refresh icon (↻) for the "check for updates" button in the header, making its purpose clearer.
