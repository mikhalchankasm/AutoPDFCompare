# PDFCompare Local v0.1.14

First release with a Windows installer and in-app auto-update. MCP exclusion-zone parity. README redesign. Dialog fixes.

## Added

- **Windows installer** — `PDFCompareLocal-setup.exe` (Inno Setup): per-user install into `%LocalAppData%\Programs` (no admin rights / UAC), Start menu and optional desktop shortcuts, clean uninstall, in-place upgrades. Attached to this and every future release next to the EXE and portable ZIP.
- **In-app auto-update**: when a new release is available, the installed app offers "Download and install now" — it downloads the installer, updates silently and restarts itself. Running from source keeps the "open the release page" flow; "skip this version" works in both.
- **MCP: text forms for exclude zones** — `start_pdf_comparison` / `rerender_pdf_comparison_pages` accept `exclude_regions` as percent text `"x,y,w,h;…"` or JSON with `unit`/`anchor`, exactly like the GUI field; empty string on re-render means "inherit".
- **MCP: picker parity** — `pick_pdf_exclude_region` opens the same visual editor as the GUI (mm grid, paper formats, several regions, move/resize, per-region corner anchors), takes `existing` zones for editing, and returns an `exclude_regions` list.

## Changed

- README redesigned: annotated GUI screenshot with a numbered 10-zone legend, install options table (installer / portable EXE / from source), exclude-zone syntax reference with mm/anchor examples, report overview, update behavior.
- Added a repository review prompt for external/AI reviewers (`docs/REVIEW_PROMPT.md`).

## Fixed

- "Выбрать…" dialogs (old/new PDF, output folder) now open at the folder already written in the field instead of the OS's last-used location.
- "Открыть папку" falls back to the output folder from the field when no comparison has been run yet.
- If tkinterdnd2 is importable but its tkdnd Tcl package fails to load, the app starts without drag-and-drop (with a status-bar notice) instead of crashing on launch.

## Verification

- Test suite: `119 passed, 9 subtests passed`; ruff and mypy clean.
- Installer built by CI on windows-latest (Inno Setup 6) and verified present in build artifacts.
- MCP smoke: comparisons started with text/JSON/anchored exclusion forms completed end-to-end; re-render with empty-string override inherits the original zones.
