# PDFCompare Local v0.1.9

Hotfix for the exclusion-picker validation error.

## Fixed

- Resolved the "coordinates must fit in 0..100%" error that appeared when starting a comparison after drawing an exclusion region with the visual picker. The picker rounded each coordinate independently, so `x + w` could exceed 100% by a tiny fraction and be rejected. The picker now clamps width/height so `x+w` and `y+h` never exceed 100; the region validator also tolerates sub-0.01% overflow from rounding instead of rejecting it.

- Test suite: `104 passed, 9 subtests passed`.
