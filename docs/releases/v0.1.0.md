# PDFCompare Local v0.1.0

First public release of PDFCompare Local, a Windows-oriented local tool for comparing two PDF revisions and generating an HTML visual diff report.

## Highlights
- Local-only PDF comparison, no cloud upload.
- Windows GUI with drag-and-drop, RU/EN language switch, run history, and report opening helpers.
- CLI mode for repeatable comparisons.
- Page mapping for inserted and removed sheets.
- Visual HTML report with summary, page navigation, OLD/NEW/DIFF views, and slider comparison.
- Parallel page comparison with configurable worker count.
- Optional selected-page re-rendering for tuning DPI and stroke tolerance after a run.

## Downloads
- `PDFCompareLocal.exe` for users without Python.
- `PDFCompareLocal-portable.zip` for Python-based portable use and easier diagnostics.

## Verification
- `python -m py_compile compare_pdfs.py pdfcompare_gui.py`
- `python -m unittest discover -s tests`
- `./scripts/package_portable.ps1`
